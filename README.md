# Oracle DBMS Course – Beginner to Expert

A structured learning repository for Database Management Systems (DBMS) using Oracle SQL. This repository contains notes, SQL queries, practical exercises, and learning resources to build database concepts from the fundamentals to advanced topics.

## About This Repository

This repository is created as part of my DBMS learning journey. It focuses on understanding database concepts, writing SQL queries, and practicing database operations using Oracle.

The goal is to develop a strong foundation in DBMS and gain practical experience with relational databases.

## Topics Covered

* Introduction to DBMS
* Database Architecture
* Relational Database Model
* Entity Relationship (ER) Model
* SQL Fundamentals
* DDL (Data Definition Language)
* DML (Data Manipulation Language)
* DQL (Data Query Language)
* DCL (Data Control Language)
* TCL (Transaction Control Language)
* Constraints and Keys
* SQL Joins
* Subqueries
* Aggregate Functions
* Views
* Indexes
* Normalization
* Functional Dependencies
* Transactions
* Concurrency Control
* PL/SQL Fundamentals

## Technologies Used

* Oracle Database
* Oracle SQL
* SQL Developer
* Git & GitHub



## Learning Objectives

* Understand core DBMS concepts.
* Learn to design and manage relational databases.
* Write SQL queries efficiently.
* Perform database operations using Oracle.
* Understand normalization and database design.
* Practice real-world database problems.


## Purpose

This repository serves as a personal learning archive and a reference for students who want to learn Oracle DBMS from scratch.
